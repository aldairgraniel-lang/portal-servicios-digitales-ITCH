Portal de Servicios Digitales - ITCH
Este repositorio contiene el código fuente y la documentación del Portal de Servicios Digitales desarrollado para el Instituto Tecnológico de Chetumal (ITCH). El sistema está diseñado para optimizar, automatizar y gestionar trámites y procesos académicos de los estudiantes, garantizando una interfaz moderna y eficiente.

🚀 Características Principales
Módulo de Preinscripción de Verano: Gestión de períodos, cupos y registro simplificado para los alumnos.

Cartas de No Inconveniencia de Inglés: Generación, validación y exportación de documentos académicos oficiales.

Solicitudes de Justificación: Módulo para que los estudiantes gestionen sus justificaciones de manera digital.

Exportación de Reportes: Funcionalidad integrada para exportar listas y solicitudes directamente a Excel y Word.

🛠️ Tecnologías Utilizadas
El portal está construido con un stack robusto para asegurar su rendimiento y escalabilidad:

Backend: PHP

Base de Datos: MySQL

Frontend: Bootstrap (con estilos organizados en archivos CSS separados)

Entorno de Desarrollo: Docker y XAMPP

Control de Versiones: Git y GitHub

🎨 Diseño e Interfaz
La interfaz está diseñada para ofrecer una experiencia visual inmersiva y cómoda, enfocada en la usabilidad:

Estilo Glassmorphism: Uso de contenedores transparentes y desenfocados para un aspecto profesional y moderno.

Modo Oscuro (Dark Mode): Interfaz optimizada para pantallas AMOLED, reduciendo la fatiga visual y mejorando el contraste.

📋 Requisitos e Instalación
Para levantar y probar el proyecto en tu entorno local, asegúrate de cumplir con los siguientes requisitos:

Git instalado en tu computadora.

Un servidor local como XAMPP o contenedores con Docker para ejecutar PHP y MySQL.

Visual Studio Code con el ejecutable de PHP configurado en el PATH del sistema.

Pasos para iniciar el proyecto localmente:
Clona el repositorio:

Bash
git clone https://github.com/aldairgraniel-lang/portal-servicios-digitales-ITCH.git
Copia y configura tus variables de entorno en el archivo .env (asegúrate de mantener fuera del control de versiones los archivos de configuración).

Inicia tu servidor local (Apache/MySQL) y monta la base de datos necesaria para los módulos.
